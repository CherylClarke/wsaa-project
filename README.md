Movie Collection CRUD App

This project is a Movie Collection CRUD web application built using Flask and SQLite.

The application allows users to:
•	Add movies
•	View movies
•	Edit movies
•	Delete movies

The project uses REST API routes to perform CRUD operations on a SQLite database. The frontend is built with HTML, Bootstrap, and JavaScript using fetch/AJAX requests.
Technologies used:
•	Flask
•	SQLite
•	HTML
•	Bootstrap
•	JavaScript


To run the project locally:

pip install -r requirements.txt

python app.py

Then open:
http://127.0.0.1:5000
